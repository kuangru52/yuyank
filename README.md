#  本项目完全是再在[语燕输入法](https://github.com/gurecn/YuyanIme)的基础上开始的。
#   在语燕输入法的基础上，增加了
          1，九宫格双拼。默认方案为我经常使用的砖头鹏方案，内置了米旮旯2，米旮旯3，辜氏2，辜氏2低重码
          2，九宫格，全键，乱序17，所有双拼方案均可自定义。
#  本程序只适合尝鲜，无法做到日常使用，反正我是不用。慢慢优化，为逃离百毒做准备。
